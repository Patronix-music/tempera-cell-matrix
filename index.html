Tempera Cell Matrix — Help

Basics

8 columns × 8 rows. Columns are Samples. Rows are Cells (1..8).

  • Click a cell to select it, use the settings panel for name/volume/fades/fit/reverse/mute/lock.
  • Double‑click a cell, press space or ▶ to play.
  • Arrow keys move through the matrix. With Auto preview on, the newly selected cell also plays automatically when you click a matrix cell with the mouse.
  • Matrix shortcuts: N=Normalize, A=Auto fade, Shift+A=Auto fade settings, E=Wave Editor, F=Trim/Fit toggle, T=Tuner, S=Export all ZIP, Ctrl/Cmd+S=local quick save/recovery, R=Reverse, M=Mute, L=Lock, Enter=Load, Delete/Backspace=Clear.
  • Quick save stores a local recovery snapshot without audio, including Matrix slicer work. Autosave does the same about once a minute when something changed and can be paused with the header button.
  • Quick-save recovery keeps Random Sources metadata. Use Choose Sources in the relink window to reattach multiple source folders or add relink-only folders.
  • Esc stops playback. In editors: Esc hides the zoom window first, then closes the editor.
  • Tempo mode uses BPM + Beats/cell and distributes rounding across 8 slices (no drift).
  • Drag cell→cell: swap. Alt + drag: copy.

Editing

Use the Cell settings panel to change Gain, Mute, Reverse, Fade In/Out, Cell Pitch, Trim/Fit and Lock state.

  • Auto fade fills the existing Fade In/Out sliders from the audible cell/slice length. A applies the saved scale; Shift+A or Shift-click opens Click-safe/Soft/Strong presets and custom Start/End percentage fields. Click-safe is the default; the button turns green when a non-default scale is saved.
  • Cell Pitch is a per-cell semitone offset used for TCM playback and WAV/ZIP/Grid audio export.
  • Tuner opens a compact pitch helper for the selected loaded cell. It loops the cell while you adjust Cell Pitch with the slider or keys; it works best on monophonic or stable-pitch samples.
  • Fit all quickly enables Trim/Fit where the loaded sample is longer than the target cell length.
  • Normalize peak-normalizes the current audible cell/selection audio and also works on multi-selected cells. Cmd/Ctrl+Z restores Normalize and selected-cell Clear actions.
  • Lock col and Lock row bulk-toggle the existing cell locks in the current column or row.
  • Fades are drawn as an envelope overlay on top of the oscilloscope.
  • Gain is shown as a small bar under the oscilloscope (no text).

Slice Editor

Used by Slice 8. Drag or resize the 8 slice blocks. Each slice is limited to the max cell length.

  • Click a block to focus it and space for playback.
  • Drag inside selection to move. Drag edges to resize.
  • Snap optionally snaps released L/R slice handles to the nearest nearby zero-crossing, and also snaps once after L/R arrow nudges settle. It does not affect Move, Space or Auto.
  • L / M / R — choose Left edge / Move / Right edge control (also affects Zoom window and arrow nudges).
  • Zoom window appears for closeup editing the slice. +/- zooms, Z toggles Auto‑Norm.
  • Slice view zoom: press +/- to zoom around the focused slice (only when the zoom window is hidden).
  • Tab/Shift+Tab jumps between the 8 slices for fast editing.
  • Esc: if zoom window is visible → hide zoom. Otherwise → close editor.
  • ← / → nudge selection • Shift=coarse • Alt/Option=fine.
  • Auto tiles 8 slices evenly.
  • Apply commits 8 slices to the 8 cells in 1 column (used for playback + export).
  • Undo multiple times a step back when editing. Also after apply.
  • Zoom On/Off turns the zoom window on or off in both the editors.

Wave Editor

Click the waveform in a cell to open the full source waveform and choose the exact slice for that cell.

  • Click the mini-wave in a cell to open the full source waveform.
  • Drag inside selection to move. Drag edges to resize.
  • L / M / R — choose Left edge / Move / Right edge control (also affects Zoom window and arrow nudges).
  • Zoom window appears for closeup editing the slice. +/- zooms, Z toggles Auto‑Norm.
  • Esc: if zoom window is visible → hide zoom. Otherwise → close editor.
  • ← / → nudge selection • Shift=coarse • Alt/Option=fine.
  • Trim writes the current selection into the cell. Snap On snaps left/right trim edges once after you release the handle or pause after an L/R arrow nudge; if no zero crossing is close, the edge stays where you put it. Snap Off keeps the exact unsnapped selection.
  • Undo multiple times a step back when editing. Also after apply.
  • Reset for default slice cell-length and position.
  • Zoom On/Off turns the zoom window on or off in both the editors.

Matrix Slicer

Load one long sample, place In/Out points, and spread the selected parts across the whole 8×8 matrix.

  • Load new loads one source sample for Matrix Slicer.
  • I sets an In point and O sets an Out point at the dotted cursor. During playback, I/O use the moving playhead; after Stop, O can use the stopped playhead.
  • Point pairs become segments. Long segments automatically overflow across as many empty unlocked cells as needed.
  • Click a colored segment in the 64-cell strip to select and zoom that segment. Click it again or press Esc to leave segment focus. In segment focus, Tab/Shift+Tab jumps to the next/previous segment.
  • In segment focus, use the meta row to name the segment, drag the middle volume line up/down, drag the top fade balls inward for fade in/out, and press T to tune segment pitch. Export segs and Apply use these segment edits.
  • When a segment is selected, the segment meta row shows In/Out, cell count and an optional name field. Named segments export as name.wav and Apply uses the name as the matrix cell name.
  • Space previews the selected segment, or plays from the dotted cursor when no segment is selected. In segment zoom, selecting the Out point previews into the segment ending: from In for one- or two-cell segments, or at least one cell-part before Out for longer segments.
  • Select an In/Out marker to drag it. ←/→ nudges it, Shift is coarse and Alt/Option is fine.
  • +/- zooms around the selected point. Snap moves the selected point to the nearest nearby zero crossing and is remembered.
  • From cel makes Apply start at the currently selected matrix cell, then continue through the next empty unlocked cells.
  • Delete seg or D removes the selected complete In/Out segment without clearing the other points.
  • Export segs exports complete segments as separate WAV files; unnamed segments use the current Name template.
  • Export WT exports the selected segment as one experimental 64 × 2048 sample mono wavetable WAV at 48 kHz using cycle scan when possible.
  • Undo and Cmd/Ctrl+Z undo Matrix Slicer edits.
  • Apply writes the result to empty unlocked cells in matrix order.

Loading audio

  • Cell Load: click Load inside a cell or drop a file onto that cell.
  • Long samples can stay in the current cell (trim), overflow below, use Overflow + Fit, or use Overflow + Tune to open Tuner before applying overflow.
  • Overflow + Tune: tune the temporary start cell first, then click Apply overflow or press Enter. Esc cancels and restores the previous cell state.
  • When one long sample is loaded with overflow, the column name at the top is auto-filled from that sample name.
  • Slice 8: pick one file → opens Slice Editor where you can drag/resize 8 blocks, then Apply to the column.
  • Load 8: select up to 8 files → fills the 8 cells top→bottom. Duplicate selections are skipped. If you select more than 8 unique files, it randomly picks 8 for the current column. When a live Sources list is active, this same button changes to Random 8 and fills the unlocked cells in that column from the shared pool instead.
  • Remix in the inspector creates a quick column variant in the next empty column to the right: Reverse, Rotate +1, Odd/Even, or Random order. Remix-generated variants refresh their mini-waves and file labels immediately, and are treated as derived helper columns so they do not get duplicate-red warning styling.
  • Prep Loop in the inspector loads one sample into the selected column, fits it to the current Tempo (BPM) grid, and slices it cleanly across the 8 cells. This is a simple BPM loop-prep helper and requires Tempo mode to be enabled.
  • Locked cells are retained during Load 8, Random 8 and Random 64. If a random fill must reuse a file, duplicate-loaded cells get a red border.
  • Random 64: if a live Sources list exists, it uses that combined folder pool. Otherwise it still lets you pick one folder (subfolders included) and fills all unlocked cells randomly. The button turns blue when filters are active.
  • Sources next to Random 64 opens a reusable multi-folder source list shared by Random 64 and the column Load 8 / Random 8 action. Use Filters... inside Sources or Shift + click Random 64 to open the filter dialog:
    • Include: only filenames containing any token (comma separated)
    • Exclude: skip filenames containing any token (comma separated)
  • Drag and drop samples in cells and columns

Import / Export

Import preset: load the preset JSON exported by this app (e.g. zz_TCM-Preset_MyPreset_20260111.json), or load the exported ZIP directly for automatic embedded-sample relinking. JSON import still asks for your top-level sample folder. Subfolders are included. The folder overlay shows example filenames to help you pick the right folder.

  • Quick save recovery: when Autosave is active, TCM stores local recovery data about once a minute. Use Recover to open relink; choose a folder, a TCM ZIP, or Choose Sources for multiple Random Source folders and relink-only recovery folders.
  • Export in a column: exports that column to WAV.
  • The header Name template supports placeholders such as {col}, {colname}, {celname}, {mode}, {bpm}, {sr}, {frames} and {date}. Recent templates can be selected from the dropdown; the default template stays protected.
  • Export 8 in a column: exports the 8 cells as separate WAV files (downloaded as one ZIP). Filenames use Sample + C# by default, or the Name template when it includes {celname}.
  • Export all (ZIP): exports up to 8 columns and downloads one ZIP file.
  • Empty columns are skipped.
  • Template only: export settings + layout only, with no audio files in the ZIP. Good for reusing a canvas setup and swapping samples later.
  • Include original samples in ZIP for handpicked samples in the Matrix and TCM preset sharing.
  • Export .canvas: optionally use an existing Tempera .canvas as a settings template; TCM preserves its settings and replaces the track audio.
  • Export grid: exports loaded cells as one evenly spaced 4/8/16/32/64-slice WAV for Grid/Slice samplers such as Digitakt II, MPC/Force, SP-404MKII, Octatrack, Polyend Tracker/Play and 1010music Blackbox.
  • Export grid rules: empty cells are skipped. If the loaded count is not exactly 4/8/16/32/64, TCM uses the nearest lower grid size in matrix order, e.g. 10 loaded cells exports the first 8 and skips the last 2.
  • Export grid sample rate: choose 48 kHz for Digitakt II / TCM default, or 44.1 kHz for wider sampler compatibility. Grid WAVs are exported as 16-bit PCM.
  • Export WT: exports loaded matrix cells as one experimental 64 × 2048 sample mono wavetable WAV at 48 kHz using Cycle scan per cell when possible.
